# wl2028rating

校内训练比赛的 Rating 与奖牌统计页面。

## 项目结构

```text
.
├─ index.html          # 页面骨架
├─ styles.css          # 页面样式
├─ app.js              # Rating / 休眠 / 奖牌计算与渲染
├─ data/
│  └─ ratings.csv      # 唯一历史成绩数据源
└─ tools/
   └─ update.py        # 追加新比赛的辅助脚本
```

以后日常更新原则上只需要修改 `data/ratings.csv`。网页会在打开时自动读取该文件并重新计算所有 Rating、休眠状态和奖牌。

## ratings.csv 格式

第一列是选手 ID，后续每一列是一场比赛。

- `12`：本场排名 12。
- `3-队伍名`：排名 3，且属于同名队伍；同一队伍成员使用相同队伍名。
- `-1`：当时已经存在的选手缺席本场。
- `0`：该选手在这场比赛时尚未加入统计系统（通常只出现在新选手的历史列）。

所有数据行必须与表头列数完全一致。

## 添加一场新比赛

准备一个结果文本，例如 `results.txt`：

```text
Jian132363 1
Mooos 2-uwu
yrjzs 3-佬佬菜菜带带
```

然后执行：

```bash
python tools/update.py 2026.09.16 results.txt
```

脚本会：

1. 检查比赛名是否重复；
2. 检查 CSV 每行列数；
3. 给未参赛的老选手追加 `-1`；
4. 给新选手的全部历史比赛补 `0`；
5. 对疑似拼错的 ID 给出旧 ID 候选并默认停止；
6. 写入前保留 `data/ratings.csv.bak` 备份；
7. 输出参赛人数、新选手和冠军摘要。

确认疑似相似 ID 确实是新选手时，可使用 `--allow-new`。只想检查而不写入时使用 `--dry-run`。

## 奖牌规则

单场只计最高的一档：

- 参赛人数 ≥ 20 的冠军：金冠；
- 其余场次冠军：银冠；
- 非冠军前 `ceil(n × 10%)`：金牌；
- 再到前 `ceil(n × 30%)`：银牌；
- 再到前 `ceil(n × 60%)`：铜牌。

主榜名字旁只显示该选手历史最高级别的 **金冠 / 银冠 / 金牌** 标志；银牌、铜牌只在奖牌榜统计。

奖牌榜按金冠、银冠、金牌、银牌、铜牌数量依次降序排序；完全相同后按当前 Rating、ID 排序。

## 本地预览

页面通过 `fetch()` 读取 `data/ratings.csv`，因此不要直接双击 `index.html`。在仓库根目录启动一个本地 HTTP 服务，例如：

```bash
python -m http.server 8000
```

然后访问 `http://localhost:8000/`。GitHub Pages 环境可直接使用。
